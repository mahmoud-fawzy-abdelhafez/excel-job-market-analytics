# Excel-job-market-analytics

## Introduction

As a former job seeker, I was always surprised by the lack of structured insights into the data science job market.  
This project explores real-world job postings to understand which skills employers value most and how they impact salaries.  

By leveraging Excel’s advanced features—**Power Query, PivotTables, Power Pivot, DAX, and Charts**—I analyzed job titles, salaries, locations, and skills to uncover trends and correlations that can help professionals navigate their careers.

---

## Key Questions Analyzed

1. **Do more skills lead to better pay?**  
2. **What are the salary ranges for data jobs across regions?**  
3. **Which skills are most common among data professionals?**  
4. **What are the top-paying skills in the market?**  

---

## Excel Skills Applied

- 📊 PivotTables & PivotCharts  
- 🔍 Power Query (data cleaning & transformation)  
- 💪 Power Pivot (data modeling)  
- 🧮 DAX (Data Analysis Expressions)  
- 📈 Data visualization and dashboards  

---

## Dataset

The dataset is based on real job postings from **2023**, focusing on data-related roles. It includes:  

- 👨‍💼 **Job Titles**  
- 💰 **Salaries**  
- 📍 **Locations**  
- 🛠️ **Skills**  

The data was cleaned, transformed, and modeled within Excel to enable structured analysis.

---

## Findings & Insights

### 1️⃣ Do more skills get you better pay?  
- Jobs requiring multiple skills (e.g., **Senior Data Engineer, Data Scientist**) show **higher median salaries**.  
- Roles needing fewer skills (e.g., **Business Analyst**) tend to offer lower pay.  
- 👉 Specialized skill sets translate into higher market value.  

### 2️⃣ What’s the salary for data jobs in different regions?  
- **US-based roles** consistently pay more than international roles.  
- High-tech jobs show the largest salary disparity, reflecting the tech industry’s concentration in the US.  
- 👉 Location matters when it comes to salary expectations.  

### 3️⃣ What are the top skills of data professionals?  
- **Python** and **SQL** dominate the skillset, forming the foundation for most data jobs.  
- **Cloud technologies** like AWS and Azure are rising in demand.  
- 👉 Staying competitive means mastering both foundational and emerging skills.  

### 4️⃣ What’s the pay for the top 10 skills?  
- Skills like **Python, SQL, and Oracle** are linked to **higher median salaries**.  
- General tools (e.g., PowerPoint, Word) correlate with **lower salaries**.  
- 👉 High-value technical skills are key drivers of higher compensation.  

---

## Conclusion

This project demonstrates how Excel can be used as a powerful analytics tool to uncover meaningful insights from real-world job market data.  

**Key takeaways:**  
- Acquiring multiple in-demand skills increases earning potential.  
- Python, SQL, and cloud technologies are strongly associated with higher pay.  
- Location significantly influences salary ranges.  

I hope this analysis serves as a useful resource for aspiring data professionals and provides direction for developing skills that maximize career opportunities.
